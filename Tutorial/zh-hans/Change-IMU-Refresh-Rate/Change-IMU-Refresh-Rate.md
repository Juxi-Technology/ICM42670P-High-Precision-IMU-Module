# 更改IMU模块刷新率

**结论先说**：**串口可以设 10–100 Hz；I2C 设不了，固定约 115–118 Hz。** 设置写在闪存里，断电保持。

---

## 一、串口：怎么设

### 指令格式

```
7E 23 07 60 <频率Hz> 5F <校验>
```

| 字段 | 值 |
|-|-|
| 帧头 | `7E 23` |
| 长度 | **固定 `0x07`**（整帧 7 字节） |
| 功能字 | **`0x60`** = 设置数据输出频率 |
| 参数1 | 频率，**10\~100 Hz** |
| 参数2 | **固定 `0x5F`** |
| 校验 | 从 `7E` 累加到 `5F`，取低字节 |

> ⚠️ **参数2 的 `0x5F` 不能漏。** 漏了之后长度和校验都会错，而模块**不报错、不返回失败，只是整帧不理会**——很容易误判成"这个模块不支持调频率"。

### 常用帧

| 频率 | 完整帧 |
|-|-|
| 10 Hz | `7E 23 07 60 0A 5F 71` |
| **20 Hz** | `7E 23 07 60 14 5F 7B` |
| 25 Hz | `7E 23 07 60 19 5F 80` |
| 50 Hz | `7E 23 07 60 32 5F 99` |
| 100 Hz | `7E 23 07 60 64 5F CB` |

### 怎么发

- **串口助手**：115200 8N1，直接发上面那串十六进制
- **官方库**：`IMU_Serial_Library` 里的 `set_report_rate(hz)`
- 发完等约 1 秒生效

## 二、实测结果

| 设定 | 帧到达率 | **有效刷新率** | 最长连续重复 |
|-|-|-|-|
| 20 Hz | 20.8 Hz | **20.7 Hz** | 1 次（无重复） |
| 50 Hz | 52.9 Hz | **52.8 Hz** | 1 次 |
| 100 Hz | 105.6 Hz | **104.0 Hz** | 2 次 |

两点：

1. **有效刷新率 ≈ 到达率**，说明模块内部融合就是按设定频率跑，**低速时不会重复发同一帧**。
2. 实际值比设定值高 **3\~8%**（设 20 得 20.8，设 100 得 105.6），是模块自身时钟容差，正常。

---

## 三、断电后是否保持

设成 20 Hz → 拔掉 Type-C 等 3 秒 → 插回 → 再测：**仍是 20.7 Hz**。

**设置写在闪存里，设一次就够了**，不需要每次上电重发。

> 由此推论：**库存新模块是出厂默认 25 Hz**，所以第一次安装时设一次并确认，之后就不用管。

---

## 四、I2C：改不了

三条都验过：

| 验证方式 | 结果 |
|-|-|
| 串口设 20 Hz 后，I2C 轮询寄存器 `0x16` | 四元数仍以 **115.4 Hz** 变化（轮询 115.8 Hz）→ **不变** |
| 不加延时快速轮询（1779 Hz），看重复长度中位数 | 对应 **\~111 Hz** → 固定刷新率 |
| 用 I2C 直接写寄存器 `0x60 = 20` | 刷新率 **不变**；`0x60` 读回恒为 `0` |

**结论：I2C 的刷新率没有任何接口可以更改，固定约 115–118 Hz。** 它不是"被限流到最大值"，而是模块固定的融合输出率。

---

## 五、一个必须知道的点：轮询太快会读到撕裂值

在 471 Hz 轮询下统计"相邻两次读是否相同"，重复长度分布是：

```
长度 1: 333 次     ← 读到模块写寄存器的中间态
长度 3: 114 次     ← 正常
长度 4: 182 次     ← 正常
```

471 ÷ 4 ≈ 118 Hz，与刷新率对得上。而**长度 1 的那 333 次是撕裂**——读到了模块更新 16 字节寄存器过程中的半新半旧值。

**危险在于：撕裂出的四元数仍然是合法的单位四元数（两个相邻姿态只差约 9 ms，混出来的值很接近），模长检查拦不住它**。

👉 **轮询率不要明显快于 150 Hz。** 50\~100 Hz 最稳，这也正好是 MicroDuck 控制环（50 Hz）和 IMU 线程（100 Hz）的区间。

## 六、对 MicroDuck 的意义

|  |  |
|-|-|
| **I2C 路线**（把模块接到 HAT 的 I²C 口） | **不需要设置频率**，固定 \~115 Hz 已足够 |
| 串口路线的频率 | 只影响串口自动输出，与 I2C 读到的数据无关 |
| 文档里"出厂 100 Hz，换新模块要确认" | **只对串口用户有意义**；I2C 用户不必关心 |

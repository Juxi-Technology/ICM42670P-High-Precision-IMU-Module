## 1. MobaXterm

MobaXterm ist ein leistungsstarkes Remote-Tool, das Remote-Werkzeuge wie SHH, VNC, FTP und andere integriert.

## 3. Verwendung von MobaXterm

Suchen Sie auf dem Desktop das Symbol `MobaXterm` und öffnen Sie es:

![截图\_20250730102737\.png](../../en/Remote-File-Transfer/Images/screenshot-20250730102737.png)

## 4. MobaXterm: SSH-Fernzugriff

Wählen Sie `Session` → `SSH`: Geben Sie die IP und den Benutzernamen des entfernten Geräts ein

Zum Beispiel:

Standardinformationen des Jetson-Mainboards:

Benutzername: juxi

Passwort: juxi

Hinweis: Bei Verwendung des SSH-Fernzugriffs in MobaXterm wird in der Seitenleiste automatisch eine SFTP-Fernanmeldung verwendet

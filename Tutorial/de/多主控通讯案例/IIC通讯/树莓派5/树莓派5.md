## 2\.Gerätestatus anzeigen

Installieren Sie zunächst I2Ctool, geben Sie im Terminal ein:

```PowerShell
sudo apt-get update
sudo apt-get install -y i2c-tools
```

I2C-Gerät anzeigen

```PowerShell
sudo i2cdetect -y -r -a 1
```

## 4\.IMU-Daten anzeigen

**Wechseln Sie in das Verzeichnis \~/IMU\_Library und führen Sie die Datei IMU\_Serial\_Library\.py aus**

```PowerShell
cd ~/imu_ros2/src/IMU_ROS1/IMU_Library

# IMU-Datenausgabedatei ausführen
python3 -m IMU_Library.IMU_I2C_Library
```

![截图\_20260203175633\.png](../../../../en/多主控通讯案例/IIC通讯/树莓派5/图片和附件/截图_20260203175633.png)

Hinweis: Das Obige ist das Auslesen der Daten eines 10-Achsen-IMU. Die 6-Achsen-Version hat keine Daten des Magnetometers (Magnetometer) und des Barometers (Barometer), die 9-Achsen-Version hat keine Barometer-Daten (Barometer).

## **5\.IMU-Kalibrierung**

**Wechseln Sie in das Verzeichnis \~/IMU\_Library und führen Sie die Datei imu\_calibration\_tool\.py aus**

```PowerShell
cd ~/IMU_Library

# IMU-Kalibrierungsdatei ausführen --I2C-Kommunikationskalibrierung
# Alle Kalibrierungen durchführen (Gesamt, Magnetometer, Temperatur)
python3 -m IMU_Library.imu_calibration_tool --mode i2c --port 1

# Nur Gesamtkalibrierung
python3-m IMU_Library.imu_calibration_tool --mode i2c --port 1 --calibrate imu

# Nur Magnetometer-Kalibrierung
python3-m IMU_Library.imu_calibration_tool --mode i2c --port 1 --calibrate mag

# Nur Temperaturkalibrierung
python3-m IMU_Library.imu_calibration_tool --mode i2c --port 1 --calibrate temp
```

## 6\.Hinweise

Beim Raspberry Pi 5 muss der I2C-Pin vorab aktiviert werden.

Die Aktivierung erfolgt wie folgt:

Befehl im Terminal ausführen

```PowerShell
sudo raspi-config
```

Wählen Sie mit den Pfeiltasten der Tastatur; nach der Auswahl drücken Sie die Enter-Taste, um fortzufahren

![截图\_20260203181325\.png](../../../../en/多主控通讯案例/IIC通讯/树莓派5/图片和附件/截图_20260203181325.png)

Wählen Sie I2C, nach der Auswahl drücken Sie die Enter-Taste, um fortzufahren,

![截图\_20260203181405\.png](../../../../en/多主控通讯案例/IIC通讯/树莓派5/图片和附件/截图_20260203181405.png)

Nachdem Sie I2C ausgewählt haben, drücken Sie die Enter-Taste, wählen Sie mit den Pfeiltasten Yes und bestätigen Sie dann mit der Eneter-Taste.

![截图\_20260203181427\.png](../../../../en/多主控通讯案例/IIC通讯/树莓派5/图片和附件/截图_20260203181427.png)

Mit der Enter-Taste bestätigen

![截图\_20260203181447\.png](../../../../en/多主控通讯案例/IIC通讯/树莓派5/图片和附件/截图_20260203181447.png)

Wählen Sie mit den Pfeiltasten Finish und drücken Sie dann Enter, um die Konfiguration zu verlassen.

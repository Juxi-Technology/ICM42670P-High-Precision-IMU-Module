## 2\. Verificar o estado do dispositivo

Primeiro, instale o I2Ctool; introduza no terminal:

```PowerShell
sudo apt-get update
sudo apt-get install -y i2c-tools
```

Verificar o dispositivo I2C

```PowerShell
sudo i2cdetect -y -r -a 1
```

## 4\. Verificar os dados da imu

**Entre no diretório \~/IMU\_Library e execute o ficheiro IMU\_Serial\_Library\.py**

```PowerShell
cd ~/imu_ros2/src/IMU_ROS1/IMU_Library

# Executar o ficheiro de impressão de dados do IMU
python3 -m IMU_Library.IMU_I2C_Library
```

![截图\_20260203175633\.png](../../../../en/多主控通讯案例/IIC通讯/树莓派5/图片和附件/截图_20260203175633.png)

Atenção: os dados acima referem-se à leitura de dados de uma IMU de 10 eixos; a versão de 6 eixos não tem dados do magnetómetro (Magnetometer) nem do barómetro (Barometer), e a de 9 eixos não tem dados do barómetro (Barometer).

## **5\.Calibração da IMU**

**Entre no diretório \~/IMU\_Library e execute o ficheiro imu\_calibration\_tool\.py**

```PowerShell
cd ~/IMU_Library

# Executar o ficheiro de código de calibração do IMU --calibração de comunicação I2C
# Executar todas as calibrações (global, magnetómetro, temperatura)
python3 -m IMU_Library.imu_calibration_tool --mode i2c --port 1

# Apenas calibração global
python3-m IMU_Library.imu_calibration_tool --mode i2c --port 1 --calibrate imu

# Apenas calibração do magnetómetro
python3-m IMU_Library.imu_calibration_tool --mode i2c --port 1 --calibrate mag

# Apenas calibração de temperatura
python3-m IMU_Library.imu_calibration_tool --mode i2c --port 1 --calibrate temp
```

## 6\. Observações

É necessário ativar previamente os pinos i2c do Raspberry Pi 5.

A operação de ativação é a seguinte:

Execute o comando no terminal

```PowerShell
sudo raspi-config
```

Selecione com as teclas de direção do teclado e, após selecionar, prima a tecla Enter do teclado para entrar

![截图\_20260203181325\.png](../../../../en/多主控通讯案例/IIC通讯/树莓派5/图片和附件/截图_20260203181325.png)

Selecione I2C e, após selecionar, prima a tecla Enter do teclado para entrar,

![截图\_20260203181405\.png](../../../../en/多主控通讯案例/IIC通讯/树莓派5/图片和附件/截图_20260203181405.png)

Após selecionar I2C, prima a tecla Enter do teclado, utilize as teclas de direção para selecionar Yes e prima a tecla Eneter para confirmar.

![截图\_20260203181427\.png](../../../../en/多主控通讯案例/IIC通讯/树莓派5/图片和附件/截图_20260203181427.png)

Prima a tecla Enter para confirmar

![截图\_20260203181447\.png](../../../../en/多主控通讯案例/IIC通讯/树莓派5/图片和附件/截图_20260203181447.png)

Utilize as teclas de direção para selecionar Finish e depois prima a tecla Enter para sair da configuração.

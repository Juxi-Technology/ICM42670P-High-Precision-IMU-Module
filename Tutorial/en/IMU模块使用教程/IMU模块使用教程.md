# IMU Module Introduction

The high-precision IMU attitude sensor has a built-in **72MHz high-performance 32-bit processor**, enabling real-time attitude solving and dynamic compensation, with a data update rate of up to 100Hz, combining the advantages of fast response and stable output. It supports dual communication modes of IIC and serial port, is compatible with microcontrollers and Linux hosts, and can be seamlessly integrated into ROS systems, making it widely applicable to high-performance application scenarios such as robot motion control, UAV attitude stabilization, and intelligent navigation and positioning.

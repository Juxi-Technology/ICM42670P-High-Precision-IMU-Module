# IMUモジュール紹介

高精度IMU姿勢センサーは**72MHz高性能32ビットプロセッサ**を内蔵し、リアルタイムの姿勢演算と動的補償が可能で、データ更新周波数は最大100Hzに達し、応答が迅速で出力が安定しているという利点を兼ね備えています。IICとシリアルのデュアル通信モードをサポートし、マイコンやLinuxマスターに対応するとともに、ROSシステムともシームレスに統合でき、ロボット運動制御、ドローンの姿勢安定化、インテリジェントナビゲーション測位などの高性能アプリケーションシーンに広く適用できます。

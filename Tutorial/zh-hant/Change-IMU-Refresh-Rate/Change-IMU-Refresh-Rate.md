# 更改IMU模組刷新率

**結論先說**：**串列埠可以設 10–100 Hz；I2C 無法設定，固定約 115–118 Hz。** 設定寫在快閃記憶體中，斷電後仍保留。

---

## 一、串列埠：怎麼設

### 指令格式

```
7E 23 07 60 <頻率Hz> 5F <校驗>
```

| 欄位 | 值 |
|-|-|
| 幀頭 | `7E 23` |
| 長度 | **固定 `0x07`**（整幀 7 位元組） |
| 功能字 | **`0x60`** = 設定資料輸出頻率 |
| 參數1 | 頻率，**10\~100 Hz** |
| 參數2 | **固定 `0x5F`** |
| 校驗 | 從 `7E` 累加到 `5F`，取低位元組 |

> ⚠️ **參數2 的 `0x5F` 不能漏。** 漏了之後長度與校驗都會錯，而模組**不報錯、不回傳失敗，只是整幀不予理會**——很容易誤判成「這個模組不支援調頻率」。

### 常用幀

| 頻率 | 完整幀 |
|-|-|
| 10 Hz | `7E 23 07 60 0A 5F 71` |
| **20 Hz** | `7E 23 07 60 14 5F 7B` |
| 25 Hz | `7E 23 07 60 19 5F 80` |
| 50 Hz | `7E 23 07 60 32 5F 99` |
| 100 Hz | `7E 23 07 60 64 5F CB` |

### 怎麼送

- **串列埠助手**：115200 8N1，直接送上面那串十六進位
- **官方函式庫**：`IMU_Serial_Library` 裡的 `set_report_rate(hz)`
- 送完後等待約 1 秒生效

---

## 二、實測結果

| 設定 | 幀到達率 | **有效刷新率** | 最長連續重複 |
|-|-|-|-|
| 20 Hz | 20.8 Hz | **20.7 Hz** | 1 次（無重複） |
| 50 Hz | 52.9 Hz | **52.8 Hz** | 1 次 |
| 100 Hz | 105.6 Hz | **104.0 Hz** | 2 次 |

兩點：

1. **有效刷新率 ≈ 到達率**，說明模組內部融合就是依照設定頻率運作，**低速時不會重複送出同一幀**。
2. 實際值比設定值高 **3\~8%**（設 20 得 20.8，設 100 得 105.6），這是模組自身的時鐘容差，屬正常現象。

---

## 三、斷電後是否保留

設成 20 Hz → 拔掉 Type-C 等待 3 秒 → 插回 → 再測：**仍是 20.7 Hz**。

**設定寫在快閃記憶體中，設定一次就夠了**，不需要每次上電重新送出。

> 由此推論：**庫存新模組出廠預設為 25 Hz**，所以第一次安裝時設定一次並確認，之後就不用管了。

---

## 四、I2C：無法更改

三種方式都驗證過：

| 驗證方式 | 結果 |
|-|-|
| 串列埠設為 20 Hz 後，以 I2C 輪詢暫存器 `0x16` | 四元數仍以 **115.4 Hz** 變化（輪詢 115.8 Hz）→ **不變** |
| 不加延遲快速輪詢（1779 Hz），觀察重複長度中位數 | 對應 **\~111 Hz** → 固定刷新率 |
| 用 I2C 直接寫入暫存器 `0x60 = 20` | 刷新率 **不變**；`0x60` 讀回恆為 `0` |

**結論：I2C 的刷新率沒有任何介面可以更改，固定約 115–118 Hz。** 它並不是「被限流到最大值」，而是模組固定的融合輸出率。

---

## 五、一個必須知道的點：輪詢太快會讀到撕裂值

在 471 Hz 輪詢下統計「相鄰兩次讀值是否相同」，重複長度分布是：

```
長度 1: 333 次     ← 讀到模組寫暫存器的中間態
長度 3: 114 次     ← 正常
長度 4: 182 次     ← 正常
```

471 ÷ 4 ≈ 118 Hz，與刷新率對得上。而**長度 1 的那 333 次是撕裂**——讀到了模組更新 16 位元組暫存器過程中半新半舊的值。

**危險在於：撕裂出來的四元數仍然是合法的單位四元數（兩個相鄰姿態只差約 9 ms，混出來的值很接近），模長檢查攔不住它**。

👉 **輪詢率不要明顯快於 150 Hz。** 50\~100 Hz 最穩，這也正好是 MicroDuck 控制迴圈（50 Hz）與 IMU 執行緒（100 Hz）的區間。

## 六、對 MicroDuck 的意義

|  |  |
|-|-|
| **I2C 路線**（把模組接到 HAT 的 I²C 埠） | **不需要設定頻率**，固定 \~115 Hz 已足夠 |
| 串列埠路線的頻率 | 只影響串列埠自動輸出，與 I2C 讀到的資料無關 |
| 文件裡「出廠 100 Hz，換新模組要確認」 | **只對串列埠使用者有意義**；I2C 使用者不必關心 |

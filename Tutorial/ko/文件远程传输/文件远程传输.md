## 4. MobaXterm：SSH 원격

`Session` → `SSH` 를 선택：원격 장치의 IP와 사용자 이름을 입력합니다

예：

Jetson 보드 기본 정보：

사용자 이름：juxi

비밀번호：juxi

주의：MobaXterm에서 SSH 원격을 사용하면 사이드바에서 자동으로 SFTP 원격 로그인이 사용됩니다

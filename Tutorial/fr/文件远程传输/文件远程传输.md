## 4. MobaXterm : SSH à distance

Sélectionnez `Session` → `SSH` : renseignez l'IP et le nom d'utilisateur de l'appareil distant

Par exemple :

Informations par défaut de la carte Jetson :

Nom d'utilisateur : juxi

Mot de passe : juxi

Remarque : lorsque MobaXterm utilise SSH à distance, il se connecte automatiquement en SFTP à distance dans la barre latérale

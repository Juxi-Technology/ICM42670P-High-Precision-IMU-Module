# JX IMU Studio · 网页版上位机

JuxiTech 高精度 IMU 惯导模块的网页版上位机。无需安装软件，用 Chrome / Edge 打开页面，通过 **Web Serial** 连接 IMU 串口，即可完成数据监测、曲线观察、3D 姿态查看、动态仪表和传感器校准。

纯静态站点，无构建步骤、无第三方运行时依赖，可直接部署到 GitHub Pages。

## 功能

| 功能 | 说明 |
|------|------|
| 串口连接 | Web Serial 直连，波特率 115200，支持选择/重连串口设备 |
| 数据监测 | 加速度、陀螺仪、磁力计、欧拉角、四元数、气压计实时数值与量程条 |
| 实时曲线 | 加速度 / 陀螺仪 / 磁力计 / 欧拉角四组曲线，300 采样点滚动，暂停与清空 |
| 3D 姿态 | 透视投影 3D 立方体 + X/Y/Z 三轴箭头（始终清晰显示），拖拽旋转视角、滚轮缩放、当前位置零点标定 |
| 动态仪表 | 旋转罗盘卡（刻度与 N/E/S/W 随设备转动、顶部金色机头固定）+ 人工地平仪 |
| 传感器校准 | 整体校准 / 磁力计校准 / 温度校准 / 重置校准数据，带执行日志 |
| 轴数识别 | 连接后自动识别 6 / 9 / 10 轴硬件并回显融合算法 |
| 方向修正 | 磁偏角补偿、俯仰翻转、罗盘反向 |
| 中英切换 | 界面一键切换中文 / English，本地记忆 |

桌面版 Qt 上位机的功能均已移植；受浏览器能力限制，**I2C 连接不支持**（Web Serial 只能访问串口），数据报告频率固定为 100 Hz，与桌面版默认一致。

## 环境要求

- **Chrome / Edge 桌面版**（版本 89+），Windows / macOS / Linux 均可
- Web Serial 要求安全上下文：**HTTPS** 或 `localhost`
- 设备通过 USB 转串口（CH340 等）连接，波特率 115200
- Firefox、Safari 不支持 Web Serial

## 本地预览

在 `web` 目录下启动任意静态文件服务器：

```bash
python -m http.server 5173
```

然后打开 <http://localhost:5173>。（直接双击 `index.html` 使用 `file://` 时浏览器可能禁用 Web Serial，建议用本地服务器。）

## 部署到 GitHub Pages

1. 新建 GitHub 仓库，把本目录（`web/`）内的文件推送到仓库根目录，或放到 `docs/` 目录。
2. 仓库 **Settings → Pages → Build and deployment**：
   - 方式一（分支部署）：Source 选择 **Deploy from a branch**，Branch 选择 `main`，目录选择 `/ (root)`（若放在 `docs/` 则选 `/docs`）。
   - 方式二（Actions 部署）：Source 选择 **GitHub Actions**，使用仓库根目录的 `pages.yml` 工作流（部署目录为 `web/`），推送 `main` 后自动发布。
3. 等待 Pages 构建完成，用 Chrome / Edge 打开 `https://<用户名>.github.io/<仓库名>/`。
4. 点击「选择串口设备」，在浏览器弹窗中选择 IMU 对应的串口，再点「连接」。

GitHub Pages 默认提供 HTTPS，满足 Web Serial 的安全上下文要求。所有路径均为相对路径，部署在子路径下也能正常工作。

- **不要在本仓库或站点内分发第三方软件安装包**（串口助手、厂商上位机、远程登录/桌面工具等），除非已取得明确的再分发授权并附上许可证；大文件下载建议放在对象存储/CDN。

- 不要把密码、令牌、内网 IP 等敏感信息写进文档或示例代码。

## 安全说明

- 本工具是纯静态页面，没有后端、登录或遥测；串口数据只在浏览器本地解析和显示。
- Web Serial 权限按 **origin** 保存。当前站点部署在 `juxi-technology.github.io` 下，同一 origin 的其他 GitHub Pages 项目也会共享已授权的串口权限；请确保同源代码可信。需要更强隔离时，建议使用独立域名部署。
- 授权串口前请确认地址栏是官方地址；可在 Chrome / Edge 的站点设置中撤销串口权限。
- 页面通过 `<meta>` 设置了 Content-Security-Policy 和 `no-referrer`。GitHub Pages 不支持自定义响应头，因此 `frame-ancestors` / `X-Frame-Options` 无法生效；点击劫持防护需要自定义托管。
- 「重置校准数据」等破坏性操作有二次确认。串口握手中没有传输层认证，只应连接可信设备。
- 安全问题请私下联系 `pe@juxitech.com`，不要公开提交 issue。

## 使用流程

1. 打开页面 → 点击「选择串口设备」并授权。
2. 点击「连接」，等待固件版本与轴数识别完成（状态栏显示「已连接」）。
3. 在五个页签中查看数据、曲线、3D 姿态与仪表。
4. 校准页按指引执行校准，日志会显示设备返回的状态码。
5. 断开时点击「断开」；设备被拔出时页面会自动检测并提示。

## 协议摘要

帧格式：`7E 23 <长度> <功能字> <数据...> <校验和>`，校验和为前面所有字节之和的低 8 位。

| 功能字 | 含义 |
|--------|------|
| `0x01` | 固件版本（3 字节主/次/修订） |
| `0x04` | 原始 IMU 数据（9 × int16，加速度 ±16g、陀螺 ±2000°/s、磁力计 ±800μT） |
| `0x16` | 四元数（4 × float32，w/x/y/z） |
| `0x26` | 欧拉角（3 × float32，弧度） |
| `0x32` | 气压计（4 × float32，高度/温度/气压/参考气压） |
| `0x60` | 设置数据报告频率（10–100 Hz） |
| `0x61` | 设置融合算法（6 / 9；10 轴设备下发 9） |
| `0x70` / `0x71` / `0x73` | 整体校准 / 磁力计校准 / 温度校准 |
| `0x80` | 请求数据（后跟功能字） |
| `0x81` | 返回状态（功能字 + 状态码） |
| `0xA0` | 重置 Flash 校准数据 |

## 说明

- 网页版与桌面版共用同一套串口协议和轴数识别逻辑。
- 设备被拔出或串口异常时，页面自动回到断开状态并保留最后一次数据。
- 校准状态码由固件定义，日志中显示为「状态 N」。
